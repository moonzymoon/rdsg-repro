# RDSG reproduction package (anonymous review version)

Code and per-seed result files for "Structural rupture of rough dependency
graphs: relational anomaly detection in multivariate time series",
sanitised for double-anonymous peer review. The authors' identities are
not stated anywhere in this package; author details are provided to the
editor via the separate title page.

## Layout
- `rdsg/` — method library: granulation, copula-standardised four-tuple
  statistics, dual-channel detector, margin-preserving injections, metrics
- `baselines/` — IF/LOF point aggregations, GDN, window-divergence / VAR /
  Granger / MI baselines
- `experiments/` — the runners for every experiment table in the paper
  (map below), plus diagnostic scripts referenced in the text
- `results/paper/backup_pre_*` — frozen pre-fix snapshots of the e2 files (they cover the five relational baselines and the frozen RDSG-family arms only; the compact AT/TranAD arms are evidenced by their own result files and rerun logs). Evidence for the calibration-diagnostics sentence in the main text; the main-text tables and
  number macros are regenerated from these files by `paper/tables_gen.py`
  (with `experiments/make_derived_stats.py` deriving the pooled per-type
  and significance files). `paper/consistency_check.py` re-verifies the
  macro values listed in its header; narrative and table-body numbers can
  be traced to the frozen JSONs via the runner map below, and the
  paired/CI/seed tables in S.7 are regenerated by `gen_supp_stats.py`
- `paper/` — `tables_gen.py` (main-text table macros),
  `consistency_check.py` (re-verifies the macro subset listed in its
  header; must print ALL CONSISTENT), and the generated `gen/*.tex` macros

- `results/` — frozen per-seed result JSONs;

Coverage caveats, stated plainly: the WADI runner needs the access-controlled
raw release (below); the Anomaly-Transformer runner additionally needs a
checkout of the official public repository for the model class; the
Raspberry-Pi measurements were taken on physical hardware and ship as frozen
JSONs only. Everything else runs end-to-end from this package plus the
public datasets.

## Rerun steps (Python 3.10+, NumPy/SciPy/pandas/scikit-learn; PyTorch only for the GDN/AT/TranAD baselines)

```
pip install numpy scipy pandas scikit-learn networkx h5py
# PyTorch is needed only for the GDN baseline (experiments/run_paper_e2.py)
# and the compact AT/TranAD scorers.
# Runners resolve the results directory automatically: inside this package
# they read from and write back into ./results (merging with the frozen
# JSONs); a scratch checkout falls back to <repo-root>/../results. No OUT
# edits are needed.
# single-seed smoke test of the capability gate:
python experiments/run_e0_syn2.py --seeds 1
# full main-table runs (10 seeds each; hours on a workstation):
python experiments/run_paper_e2.py --dataset metr_la
python experiments/run_paper_e2.py --dataset beijing_air
python experiments/run_paper_e2.py --dataset pems_bay
# gas-pipeline operating curves:
python experiments/run_paper_e1.py
# regenerate every manuscript number from the frozen JSONs:
python paper/tables_gen.py    # regenerate all main-text table macros
# Windows note: set PYTHONIOENCODING=utf-8 if the smoke test hits a
# console encoding error on the check-mark character.
python gen_supp_stats.py      # Supplemental S.7 tables (paths auto-resolve)
```

## Datasets (none redistributed here)

Publicly downloadable:
- METR-LA, PEMS-BAY: DCRNN release (github.com/liyaguang/DCRNN)
- Beijing Multi-Site Air-Quality: UCI ML Repository, DOI 10.24432/C5RK5G
- MSU Gas Pipeline: Mississippi State University SCADA laboratory release
- Synthetic factor system: generated by `experiments/run_e0_syn2.py`

Access-controlled (obtain from the owners; not in this package):
- WADI A2 (and SWaT): iTrust Centre, SUTD, subject to their data-access
  agreement. For `run_wadi.py`, pre-process to `ref.npy`, `test.npy`,
  `test_label.npy` and point `$WADI_NPY_DIR` at that directory.

## Notes

- Data and dependency locations resolve from the environment or from paths
  relative to this package: `$RDSG_DATA_DIR` (default `<package>/datasets`)
  for the public datasets, `$WADI_NPY_DIR` for the pre-processed WADI
  arrays, `$AT_ROOT` (default `<package>/../Anomaly-Transformer`) for the
  official Anomaly-Transformer checkout used by the AT runner.
- All scientific defaults (K=4, w=128, b=32, alpha=8, B=499,
  edge budget top-16/bottom-24) are the frozen values documented in the
  manuscript and its Supplemental Material, Section S.8.
- Hyperparameters were fixed once on the synthetic gate and reused
  unchanged on all real datasets; no per-dataset tuning was performed.
